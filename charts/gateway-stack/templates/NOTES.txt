WARNING: guardianUI.enabled=true but ingress.controlPlanePath is "/", so the
console has NO Ingress route -- the control-plane API occupies the host root.
Set ingress.controlPlanePath and controlPlane.apiBasePath to a prefix such as
/api, or reach the console directly with:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "gateway-stack.uiServiceName" . }} 8080:{{ .Values.guardianUI.service.port }}
